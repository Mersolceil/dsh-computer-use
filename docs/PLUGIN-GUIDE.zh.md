# 开始使用浏览器操作

让 DSH 中的模型使用独立浏览器完成网页任务。默认后台运行，不切换程序坞里的 Chrome；临时会话不带入个人浏览器的登录状态。

本插件以无障碍语义树定位控件，支持搜索、表单、多标签页、历史导航、截图及专用目录文件上传。本页介绍浏览器组件。另有实验性 macOS 桌面适配器，见[桌面控制说明](DESKTOP-CONTROL.md)；下载和登录人工接管尚未实现。

## 第一次使用

1. 安装后点击“立即启用”，确认本页组件为“运行中”。本机首次安装可实时加载；升级替换后若组件未运行，先结束任务，关闭并重新打开 DSH，再检查状态。
2. 浏览器运行时需要单独安装。在终端执行下面的固定版本命令；已安装者无需重复执行。

```sh
npx --yes --package=playwright@1.63.0 playwright install chromium-headless-shell
```

3. 在源码目录执行 `npm run lab` 启动本地练习台，保持运行。
4. 在 DSH 新会话中输入：

> 仅使用 cu_browser 工具打开 http://127.0.0.1:4173，搜索“浏览器”并读取结果。创建任务：标题“完成实验报告”，描述“核对原始结果”。只保存一次，检查保存结果，截图后关闭浏览器。

轨迹中应出现 `cu_browser_open`、填充、点击、截图及 `cu_browser_close`。成功依据是页面的保存结果，不能只看模型回答“已完成”。截图会作为真实图片返回；模型能否理解图片取决于所选模型和 DSH 的图片能力配置。

## 操作其他网站

默认只允许练习台 `http://127.0.0.1:4173`。其他网站须在当前 DSH profile 的 `cordis.patch.yml` 中为 `computer-use-v1` 配置 `allowedOrigins`。**当前没有插件自带的图形配置表单。**保留 profile 原有条目，添加或合并以下覆盖；不要覆盖整份文件：

```yaml
- id: computer-use-v1
  config:
    headless: true
    allowedOrigins:
      - http://127.0.0.1:4173
      - https://example.org
```

只填写协议、主机和必要端口，不带路径或末尾斜杠；不支持 `*`。网站依赖其他来源时按任务核对后添加。修改后确认插件重新加载，再建立浏览器会话。该限制不是操作系统防火墙。

上传默认关闭。需要时配置 `uploadRoots` 为已存在的专用目录绝对路径数组，再将准备上传的文件放入目录。模型先点击网页选择文件按钮，取得 `chooser_id`，再调用 `cu_browser_upload`。不要把整个个人目录设为上传目录。选择可能自动发送文件，结果不确定时先检查页面，不重复提交。

## 遇到问题

| 现象 | 处理方法 |
|---|---|
| 找不到 `cu_browser` 工具 | 确认插件和组件均启用；在新会话中检查轨迹 |
| `BROWSER_MISSING` | 执行上面的固定版本运行时安装命令；下载完再重试 |
| `ORIGIN_DENIED` 或资源未加载 | 核对被拒绝的精确来源和当前 profile 配置 |
| `STALE_TARGET` / `WRONG_TAB` | 重新观察，或切到引用所属标签页；使用新返回的引用 |
| 点击超时、保存状态未更新 | 先观察或等待页面准确文字，核对是否已提交；不要盲目重试保存 |
| 图像被拒绝 | 检查模型和 provider 图片能力；普通控件可继续用语义树操作 |

在源码目录运行 `npm run doctor` 可检查后台浏览器的真实点击和截图。`npm run doctor -- --json` 输出结构化报告。也可用 `--config browser-config.json` 检查单独的原始配置 JSON 对象；检查不保存或应用配置，不读取 DSH 凭据，也不证明插件已在 DSH 启用。

源码、完整测评方法和历史结果随交付包提供。该版本仍是候选版，本地练习通过不能代表任意网站都能完成。
